## 1. 프로젝트 개요

- **프로젝트명**: SAFE — Safe-driving Analytics & Forecasting Engine

- **문서 목적**: 서비스에 필요한 데이터 묶음의 출처, 수집 목적, 항목별 정의(형식/필수여부/예시값/허용범위)를 명세

## 2. 데이터 식별 — 5대 카테고리

| No | 데이터명 | 관련 요구사항 | 출처 |
|---|---|---|---|
| 1 | 인구 관련 데이터 | RF-2.0 | 행정안전부, e-나라지표 |
| 2 | 자동차 관련 데이터 | RF-1.0 | 경찰청, KOSIS, 국토교통통계누리 |

각 데이터는 **지역·연도** 기준으로 서로 연계되어, 인구 대비 자동차 등록·사고 발생 수준을 함께 분석하는 데 활용됩니다.

## 3-1. 인구 데이터

**출처**: 행정안전부, e-나라지표
**활용 목적**: 지역별 인구 특성과 연령대별 분포를 분석하고, 인구수와 자동차 등록대수·교통사고 발생 건수를 비교하여 지역별 교통환경 분석

| 파일 | 주요 항목 |
|---|---|
| 주민등록인구및세대현황(월간) | 행정구역, 연도, 총인구수, 세대수, 세대당 인구, 남/여 인구수, 남녀 비율 |
| 지역별 인구(e-나라지표) | 연도, 인구, 인구밀도, 지역 |

---

## 3-2. 자동차 데이터

**출처**: 경찰청, KOSIS, 국토교통통계누리
**활용 목적**: 지역별 자동차 보유 현황과 등록 추이 분석, 인구 대비 등록대수 산출

| 파일 | 주요 항목 |
|---|---|
| 운전면허소지자현황 (성별/연령대별/지역별) | 연도, 면허종류(1·2종/대형·보통·소형), 성별, 연령대, 지역 |
| 운전면허 자진반납 취소처분현황 (2023/2025) | 지역, 나이 |
| 운전면허소지자 지역별 종별 현황 | 지역, 성별, 면허종류 |
| 자동차등록현황보고 | 월-년도, 도시명, 차량종류 |

---

## 3-3. 교통사고 데이터

**출처**: TAAS 교통사고분석시스템, TMACS 교통안전정보관리시스템
**활용 목적**: 지역별·연도별 사고 발생 추이·유형 분석, 인구·자동차 등록대수와 연계한 위험도 분석

| 파일 | 주요 항목 |
|---|---|
| 가해운전자 연령대별(·시간대별) 교통사고 | 연령대, 연도, (시간대), 사고종류, 합계 |
| 기상상태별 교통사고 | 연령대, 연도, 날씨, 합계 |
| 노인운전자 사고유형별·시간대별 / 월별·시간대별 / 지역별·월별 교통사고 | 연도, 사고유형(대/중분류), 시간대, 월, 시도/시군구, 합계 |
| 연령대별·지역별 전체 교통사고 건수 | 연도, 연령대/지역, 사고유형, 합계 |
| 교통사고 지표현황(TMACS, 지역별) | 시도, 발생건수, 발생종류, 사상자수, 치사율 |

---

## 3-4. 교통법규·정책 데이터

**출처**: 도로교통공단 등
**활용 목적**: 사고 유형·법규 정보 제공, 고령운전자 정책·지원제도 안내

| 파일 | 주요 항목 |
|---|---|
| 고령운전자 교통안전교육 예약정보 | 교육일자, 지부코드, 교육반코드, 강의시간, 정원 |
| 전국 고령운전자 정책제도 | 구분, 현재 정책, 시행 상태, 대상, 핵심 내용, 담당기관, 출처 URL |
| 지역 특화 고령운전자 안전정책 | 지역, 정책/사업명, 기준연도, 대상, 지원 규모, 현재 단계 |
| 지역별 운전면허 자진반납 지원 | 지역, 정책명, 대상 연령/조건, 지원금(일반/실운전자), 지원형태, 신청방법 |

## 3-5. FAQ 데이터

**출처**: 자동차 업체 (수집 예정)
**활용 목적**: 차량 이용자의 기능·정비·고장·안전 관련 궁금증 해소, 업체별·차종별 FAQ 통합 제공

## 4. 데이터 활용 방향

- **지역 × 연도** 축을 공통 키로 삼아 인구 → 자동차 등록 → 교통사고 → 정책 데이터를 연계 분석
- 인구 대비 자동차 등록대수, 자동차 등록대수 대비 사고 발생률 등 **파생 지표** 산출
- 고령운전자 면허 자진반납 정책 **시행 전후 사고 추이 비교**
- 정부·지자체 대상 통합 대시보드 및 리포트 제공 (RF-5.0)
