# 인구
> 지역별 인구 규모와 고연령 인구 구조를 분석하여, 인구수와 자동차 등록대수·교통사고 발생 건수를 비교하여 지역별 인구수와 교통환경을 알 수 있다.

### 지역별 인구
- 지역별 인구수 비교 (가로형 막대그래프) : 지역의 수가 많기 때문에, 각각의 값을 확인하고 비교하기 위해서는 가로형 막대그래프가 적절하다.
- 전국 대비 인구 비중 (원형 그래프) : 인구 비중 표는 원형 그래프로 보는 것이 비중이 어느정도인지 파악하기 쉽다.
- 지역별 인구 상세 (표) : 아래의 표는 정확한 수치데이터와 비율표로, 해당 자료를 직접 인용하려는 사람들에게 더 효과적이다.

### 연령별 인구
- 연령대별 인구수 비교 (세로형 막대그래프) : 연령대의 수가 많진 않기 때문에, 가로형 막대그래프보다 세로형 막대그래프로 보는 것이 더 적절하다.
- 연령대별 인구 비중 (원형 그래프) : 인구 비중 표는 원형 그래프로 보는 것이 비중이 어느정도인지 파악하기 쉽다.
- 지역별 고령 인구 비율 (가로형 막대그래프) : 지역별로 고령 인구 비율이 각기 다르다. 예를 들어, 경북, 전북과 같은 지방은 60세 이상의 인구 비율은 40%대로 높으나, 서울, 대전과 같은 경우 30% 이하이다. 고령 인구수의 경우 값의 변화가 적기 때문에 원형그래프로는 직관적이지 않을 수 있어 가로형 막대그래프를 이용하였다.


# 자동차
> 지역별 자동차·운전자 특성을 분석하여, 인구 대비 등록대수를 산출할 수 있다.

### 전체 자동차 등록 현황
- 지역별 자동차 등록 분포 (단계구분도) : 단계구분도를 이용하면 각 지역이 어디인지 찾아보지 않아도 어느 곳의 등록 수가 많은지 이해하기 쉽다.
- 지역별 자동차 등록 현황 (가로형 막대그래프) : 다만 실제로 얼마나 많은지 확인하는 것이 적절하기 때문에, 가로형 막대그래프를 삽입하였다.
- 지역 및 차종별 자동차 등록대수 (가로형 막대그래프) : 각 지역마다 어떤 차종의 자동차가 얼마나 있는지 파악하기 위함이다. 해당 지역에서 일어나는 교통사고에서 화물차 자가용의 수가 많다고 했을 때, 앞선 그래프 통계가 있다면, 해당 지역의 교통사고가 화물차 자가용의 영향인지 파악할 수 있다.
- 지역 및 차종별 등록 구성비 (원형 그래프) : 차종별 비율을 파악하기 위해서는 원형 그래프가 적절하다. 

### 자동차 연도별 등록 현황
- 연도별 자동차 등록대수 추이 (선형 그래프) : 날짜별 값의 변화를 파악하기 위해서는 선형 그래프가 가장 적절하다. 현재 해당 차종의 등록대수의 변화를 파악하는 것으로 해당 차종의 수요를 알 수 있다. 만약 등록대수가 점점 떨어지고 있다면, 다른 문제를 먼저 해결하는 등의 판단을 내릴 수 있다.

**연도별 자동차 등록 증감률은 수정해야 한다고 생각합니다.**
**승용 영업용 자동차 등록 현황을 살펴보면, 자동차 등록대수의 비율이 거의 일정한데, 해당 그래프에서는 마치 엄청나게 증가한 것 같은 느낌을 줄 수 있습니다.**
**y축의 범위를 수정하거나, 증감률 계산을 2021년 기준으로 하는 것 등이 좋다 생각함니다.**

### 지역 및 차종별 등록 현황
- 지역별 자동차 등록 분포 (단계구분도) : 단계구분도를 이용하면 각 지역이 어디인지 찾아보지 않아도 어느 곳의 등록 수가 많은지 이해하기 쉽다.
- 지역별 자동차 등록 현황 (가로형 막대그래프) : 다만 실제로 얼마나 많은지 확인하는 것이 적절하기 때문에, 가로형 막대그래프를 삽입하였다.

**해당 통계를 전체 자동차 등록 현황과 합치는 것이 좋다고 생각합니다.**

### 성별 운전면허 소지자 현황
- 성별 면허 소지자 구성비 (원형그래프) : 구성비의 경우 원형 그래프가 가시성이 더 좋다.
- 연도별 성별 운전면허 소지자 추이 (선형그래프) : 연도별 추이는 그룹형 막대그래프보다, 선형그래프로 보는 것이 더 좋다. 면허의 수가 일정하다면, 그룹형 막대그래프로는 연도별 변화를 알기 어려울 수 있다.

### 연령별 운전면허 소지자 현황
- 연령별 운전면호 소지자 현황 (가로형 막대그래프) : 연령별 데이터의 경우 연령대의 폭이 짧으면 짧을수록 값이 어떻게 변하는지 알기 수월하므로 1세마다 데이터를 표시하였다. (예시 : 연령별 평균 키) 다만 연령대의 폭이 짧으므로, 세로형보다 가로형 막대그래프를 사용하는 것이 적절하다.

### 지역별 운전면허 소지자 현황
- 시도별 운전면허 소지자 분포 (단계구분도) : 단계구분도를 이용하면 각 지역이 어디인지 찾아보지 않아도 어느 곳의 등록 수가 많은지 이해하기 쉽다.
- 지역별 면허 등록 현황 (가로형 막대그래프) : 다만 실제로 얼마나 많은지 확인하는 것이 적절하기 때문에, 가로형 막대그래프를 삽입하였다.


# 교통사고
> 가해운전자·고령운전자·지역·기상 데이터를 연결하여 사고 발생 특성과 고위험 조건을 분석할 수 있다.

### 연령별 교통사고
- 연령대별 사망자 수, 연령대별 부상자 수 (가로형 롤리팝 차트) : 막대그래프는 각각의 데이터가 무게감을 주는 반면, 롤리팝 차트는 상대적으로 가벼운 느낌을 준다. 따라서, 특정 연령대를 강조하고 싶은 경우 막대그래프보다 롤리팝차트가 조금 더 적절하다.
- 연령대별 사고 규모 (가로형 막대그래프) : 연령대별 사고를 발생시킨 건수를 비교하기 위해 막대그래프를 사용하였다. 롤리팝 차트와 달리, 65세 이상의 고령운전자의 사고 건수도 강조된다.
- 연도별 사고 변화 (선형 그래프) : 연도별 변화의 경우 선형 그래프가 값의 변화를 알기 쉽다.
- 가해운전자 연령대별 사고 비교 (그룹형 막대그래프) : 각각의 데이터가 정확히 어떤 값인지 중요하지 않은 경우 그룹형 막대그래프가 더 적절하다. 연도별로 얼마나 변하고 있는지와, 어느 연령대의 사고 비율이 높은지 한눈에 들어온다.
- 연령대별 사고 미래 예측 (선형 그래프) : 연도마다 값의 변화를 보는 것이기 때문에 선형그래프를 사용하였다.

### 연령대x시간대 교통사고
- 연령대x시간대 사고 분포 (막대그래프) : 시간대마다 사고의 규모와 변화를 알기 위해 막대그래프를 사용하였다. 눈으로 볼 때 오른쪽으로 갈수록 시간이 흐른다고 알기 쉽기 때문에 세로형 막대그래프를 사요야였다.
- 전체 기준 연령대x시간대 사고 비중 (선형그래프) : 전체 연령대의 흐름과 선택한 연령대의 흐름을 비교하기 위해서는 그룹형 막대그래프보다 선형 그래프가 더 가시성이 좋다.
- 연령대x시간대 사고 발생 집중도 (히트맵) : 히트맵의 경우 어두운 곳보다 밝은 곳이 더 이목이 끌리므로, 어떤 구간이 사고가 많이 발생했는지 한눈에 들어온다.

### 고령운전자 사고유형x시간대 교통사고
- 사고유형별 규모, 세부 사고유형별 규모 (가로형 막대그래프) : 유형별 사고의 규모를 비교하기 위해 막대그래프를 인용하였다.
- 사고유형x시간대 사고 비교 (가로형 막대그래프) : 유형별로 어떤 시간대가 가장 많은 사고가 파악하는지 알기 위해 막대그래프를 인용하였다.
- 전체 사고유형x연도별 사고 추이, 예측 (선형 그래프) : 값의 변화를 알고 싶다면 선형 개르프가 적절하다.

### 고령운전자 월별x시간대 교통사고
- 월별 사고 분포 (막대그래프) : 월별마다 사고의 규모와 변화를 알기 위해 막대그래프를 사용하였다.
- 시간대별 사고 비교 (가로형 막대그래프) : 유형별로 어떤 시간대가 가장 많은 사고가 파악하는지 알기 위해 막대그래프를 인용하였다. 위의 사고유형x시간대 교통사고에서도 해당 그래프를 알 수 있으나, 탭을 이동하지 않고 확인하는 것이 좋다고 생각하여 넣었다.
- 월별x시간대 집중도 (히트맵) : 히트맵의 경우 어두운 곳보다 밝은 곳이 더 이목이 끌리므로, 어떤 때가 사고가 많이 발생했는지 한눈에 들어온다.
- 월별 고령운전자 사고 예측 (선형 그래프) : 값의 변화를 알고 싶기에 선형 그래프가 적절하다.

### 2023 vs 2025 운전면허 자진반납자 비교
- 지역별 운전면허 자진반납 비교 (그룹형 막대그래프) : 연도를 1가지 또는 2가지 선택할 수 있기 때문에, 그룹형 그래프를 쓰는 것이 적절하다. 규모의 비교도 알고 싶으므로 막대그래프가 좋다.
- 지역별 자진반납 증감 건수, 지역별 자진반납 증감률 (가로형 막대그래프) : 규모를 비교하기 위해서 막대그래프를 사용하였다. 또한 감소한 부분이 눈에 들어오기 위해서는 y축 막대 그래프가 적절하다.
- 노인 연령별 자진반납 건수 (선형그래프) : 2023년과 2025년의 연령별 반납 건수를 비교하기 위해서는 그룹형 막대그래프보다 선형 그래프가 더 가시성이 좋다.
