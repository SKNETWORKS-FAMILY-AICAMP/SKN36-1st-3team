# SAFE 데이터 분석 기법 및 예측 모델 정리

## 1. 목적별 분석 기법 선택 가이드

| 목적 | 기법 | 예시 |
|---|---|---|
| 단순히 증가/감소를 보여주고 싶다 | 추세 분석 | 2015~2025년 인구가 지속적으로 감소하고 있다 |
| 앞으로 얼마나 될지 예측하고 싶다 | ARIMA / 지수평활 / Prophet | 2030년 인구는 약 ○○만 명으로 예상된다 |
| 여러 요인이 사고에 어떤 영향을 주는지 보고 싶다 | 회귀분석 / VAR | 고령인구 증가와 고령운전자 사고 증가 사이의 관계를 분석한다 |
| 월별·계절별 사고 패턴까지 보고 싶다 | SARIMA | 고령운전자 사고가 특정 계절이나 월에 증가하는지 분석한다 |

## 2. 전체 분석 흐름

```
1. 지역별 사고 비교
        ↓
2. 연도별 사고 추세 분석
        ↓
3. 선형회귀로 추세 확인
        ↓
4. ARIMA 미래 예측
        ↓
5. Prophet 미래 예측
        ↓
6. ARIMA vs Prophet 성능 비교
        ↓
7. 최적 모델 선정
```

| 단계 | 내용 |
|---|---|
| 1. 현황 파악 | 지역별 사고 규모 비교 |
| 2. 추세 분석 | 연도별 사고 증감 및 변화 추세 확인 |
| 3. 추세 정량화 | 선형회귀를 통해 증가·감소 방향 확인 |
| 4. 미래 예측 | ARIMA를 이용한 시계열 예측 |
| 5. 다른 모델 적용 | Prophet을 이용한 미래 예측 |
| 6. 모델 검증 | 실제값과 예측값의 오차 비교 |
| 7. 최종 모델 선정 | 성능이 더 안정적인 모델을 최종 전망에 활용 |

## 3. 분석 기법 목록

| 분석 기법 | 쉽게 말하면 | SAFE 활용 예시 |
|---|---|---|
| 기술통계 | 데이터의 전체적인 모습을 평균, 합계, 최댓값 등의 숫자로 요약하는 방법 | 평균 사고 건수, 사고가 가장 많은 연령대·지역 확인 |
| 비율분석 | 전체에서 특정 항목이 어느 정도를 차지하는지 보는 방법 | 전체 면허 소지자 중 고령운전자가 차지하는 비율 분석 |
| 증감률 | 이전 기간과 비교해 얼마나 증가하거나 감소했는지 계산하는 방법 | 전년 대비 고령운전자 사고가 몇 % 변했는지 확인 |
| CAGR | 여러 해의 변화를 하나의 연평균 증가·감소율로 나타내는 방법 | 2021~2025년 자동차 등록대수의 연평균 변화율 분석 |
| 지역 비교 | 같은 지표를 여러 지역으로 나누어 차이를 확인하는 방법 | 서울·부산·인천 등 지역별 사고 규모 비교 |
| 교차분석 | 두 가지 기준을 동시에 나누어 특징을 확인하는 방법 | 성별 × 시간대별 사고 건수를 함께 비교 |
| 카이제곱 검정 | 두 범주형 특성이 서로 관련되어 있는지 통계적으로 확인하는 방법 | 성별과 사고 발생 시간대 사이에 관계가 있는지 검정 |
| 상관분석 | 두 값이 함께 증가하거나 감소하는 경향이 있는지 확인하는 방법 | 지원 수준이 높은 지역에서 면허 반납도 많은지 확인 |
| 회귀분석 | 어떤 요인의 변화와 결과의 관계를 수치로 설명하는 방법 | 지원 수준과 면허 자진반납 실적의 관계 분석 |
| 선형회귀 | 데이터의 전체적인 증가·감소 방향을 직선으로 표현하는 방법 | 연도별 사고가 전반적으로 증가하는지 감소하는지 확인 |
| 시계열 분석 | 시간 순서대로 쌓인 데이터의 변화 패턴을 분석하는 방법 | 연도별·월별 사고와 인구 변화 분석 |
| 이동평균 | 일정 기간의 평균을 반복 계산해 작은 변동을 줄이고 큰 흐름을 보는 방법 | 월별 사고의 들쭉날쭉한 변동을 완화해 추세 확인 |
| 계절성 분석 | 특정 월이나 계절에 반복되는 패턴이 있는지 확인하는 방법 | 특정 계절·월에 사고가 반복적으로 증가하는지 분석 |
| 히트맵 | 숫자의 크기를 색의 진하기로 표현해 패턴을 빠르게 찾는 시각화 | 지역 × 월, 사고유형 × 시간대의 고위험 구간 확인 |
| ARIMA | 과거 값과 이전 변화 패턴을 이용해 앞으로의 값을 예측하는 시계열 모델 | 과거 사고 건수를 바탕으로 향후 사고 수준 전망 |
| SARIMA | ARIMA에 월·계절처럼 반복되는 주기까지 고려한 예측 모델 | 월별 인구·사고 데이터의 계절성을 반영한 예측 |
| Prophet | 장기적인 추세와 반복 패턴을 학습하여 미래 값을 예측하는 모델 | 인구·자동차 등록·사고 데이터의 미래 변화 전망 |
| 텍스트 마이닝 | 많은 문장에서 의미 있는 단어와 패턴을 찾아내는 분석 | FAQ에서 자주 등장하는 교통안전 관련 키워드 분석 |
| TF-IDF | 여러 문서 중 특정 문서에서 특히 중요한 단어에 높은 점수를 주는 방법 | FAQ별 핵심 키워드 추출 및 비슷한 질문 탐색 |
| 토픽 모델링 | 많은 문서를 내용이 비슷한 주제끼리 자동으로 묶는 방법 | FAQ를 면허반납·사고처리·교통법규 등의 주제로 분류 |
| 빈도분석 | 특정 항목이나 단어가 얼마나 자주 나타나는지 세는 방법 | 정책에서 면허반납·안전교육 등의 유형이 얼마나 많은지 분석 |
| 정책 비교 | 지역 또는 정책별 지원 조건과 내용을 나란히 비교하는 방법 | 지역별 지원금·대상 연령·지원 형태 차이 비교 |
| 전후 비교 | 정책이나 사건이 발생하기 전과 후의 지표를 비교하는 방법 | 지원 확대 전후 면허 반납 또는 사고 변화 확인 |

## 4. 주요 기법 설명

**시계열 분석**
- 시간의 흐름에 따라 데이터가 어떻게 변하는지를 보는 방법
- 연도별·월별 교통사고 데이터를 시간 순서로 분석해서 사고가 증가하고 있는지, 감소하고 있는지 확인

**ARIMA**
- 과거의 값과 변화 패턴을 바탕으로 미래 값을 예측하는 모델
- 과거 사고 발생 추세를 학습시킨 뒤 향후 사고 발생 수준을 전망하는 데 활용

**Prophet**
- 미래를 예측하는 시계열 모델이며, 장기적인 증가·감소 추세나 반복되는 시간 패턴을 비교적 쉽게 반영
- ARIMA와 Prophet의 예측 결과를 비교해서 더 적합한 모델을 선정하는 방식으로 활용

**카이제곱 검정**
- 단순히 그래프상 차이가 있어 보이는 것을 넘어서 두 항목 사이에 통계적인 관련성이 있는지를 확인하는 방법
- 예를 들어 성별에 따라 사고가 많이 발생하는 시간대에 차이가 있는지를 검정할 수 있음

**상관분석과 회귀분석 차이**
- 상관분석은 두 값이 같이 움직이는지를 확인하는 것이고, 회귀분석은 한 요인이 변할 때 다른 결과가 어떻게 달라지는지를 수치화해서 분석하는 방법

## 5. 예측 모델 성능 비교 지표

| 지표 | 의미 |
|---|---|
| MAE | 예측이 실제 값에서 평균적으로 얼마나 벗어났는가 (값이 작을수록 좋음) |
| RMSE | 큰 예측 실수에 더 큰 패널티를 주면서 오차를 측정 (값이 작을수록 좋음) |
| MAPE | 실제 값 대비 평균적으로 몇 % 정도 틀렸는가 (일반인이 이해하기 쉬운 지표) |

## 7. 분석 시 주의사항

- 상관관계가 확인되더라도 바로 인과관계라고 해석하지 않는다.
  → 예를 들어 지원금과 면허 반납이 함께 증가해도 인구 규모, 교통환경 등 다른 요인이 영향을 줄 수 있음
- 연간 데이터가 2021~2025년처럼 5개 관측치뿐인 경우 장기 예측의 신뢰성이 낮을 수 있다.
  → 추세 확인 중심으로 사용하고, 미래예측은 월별처럼 관측치가 충분한 데이터에 우선 적용하는 것이 좋음
- ARIMA와 Prophet 중 하나를 그래프 모양만 보고 선택하지 않고 MAE, RMSE, MAPE 등 오차 지표를 함께 비교한다.
- 예측 결과는 확정된 미래 값이 아니라 과거 데이터 패턴을 기반으로 한 참고용 전망으로 설명한다.
