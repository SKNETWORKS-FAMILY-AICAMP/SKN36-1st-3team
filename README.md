## 📌 프로젝트 개요

**SAFE(Safe-driving Analytics & Forecasting Engine)**는 서로 다른 기관에
분산된 **자동차 등록·인구 및 고령화·고령운전자 교통사고·운전면허 및 관련
정책 데이터**를 지역 단위로 통합하여, **정부·지자체가 지역별 현황을
조회·비교하고 고령화에 따른 교통안전 변화를 분석하며 향후 변화 추이를
전망할 수 있도록 지원하는 데이터 분석 시스템**입니다.

-   **프로젝트명** : 전국 자동차 등록·고령화·교통사고 통합 분석 및
    미래전망 시스템 (SAFE)
-   **작성일 / 버전** : 2026.08.25 / v1.4
-   **한 줄 소개** : 자동차 등록부터 고령운전자 사고·면허반납 정책까지
    지역 기준으로 통합 조회·비교하는 정부·지자체용 교통안전 데이터 분석
    서비스

``` text
[인구·고령화] + [자동차 등록·운전면허] + [고령운전자 교통사고] + [교육·면허 자진반납·정책]
                                         │
                                지역 · 연도 기준 통합
                                         │
                      조회 · 시각화 → 지역 비교 → 분석 → 미래전망
```

## 🧭 개발 배경 & 문제의식

### 왜 필요한가

-   **데이터의 분산** --- 자동차 등록·인구·고령화·교통사고·운전면허·정책
    데이터가 여러 기관과 데이터셋에 흩어져 있어 지역 단위로 종합
    분석하려면 별도의 수집·정제·비교 과정이 필요합니다.
-   **현재 현황 중심의 한계** --- 현재 데이터만으로는 향후 고령화와
    교통환경의 변화를 파악하기 어려워, **과거 데이터를 기반으로 변화
    추이를 분석하고 지역별 미래 전망을 함께 확인할 필요가 있습니다.**
-   **지역별 비교의 어려움** --- 고령인구, 자동차 등록, 면허소지자,
    고령운전자 사고와 정책을 서로 다른 기준으로 제공하기 때문에 지역별
    특성을 한눈에 비교하기 어렵습니다.
-   **정책 정보의 분산** --- 고령운전자 교통안전교육과 면허 자진반납
    지원정책 등이 지역별로 달라 관련 현황과 정책을 함께 확인하기
    어렵습니다.

### 접근 방법

공공데이터와 공식 통계를 수집·정제하여 **MySQL 및 분석용 DB**에
저장하고, **Python·pandas·Streamlit·Plotly**를 활용해 지역·연도별
데이터를 조회하고 시각적으로 비교할 수 있도록 구성했습니다.

> SAFE의 미래전망은 특정 연도의 사고건수를 단정적으로 예측하는 것이
> 아니라, 확보된 과거 데이터를 바탕으로 변화 추이를 파악하고 향후 지역별
> 교통안전 수요를 살펴보기 위한 분석 기능을 지향합니다.

## 🎯 핵심 기능

### 👥 1. 인구·고령화 분석

-   지역별 인구 현황
-   주민등록 인구 및 세대 현황
-   연도별·월별 조회
-   지역별 인구 비교
-   전국 대비 지역 인구 비중
-   고령화 관련 지표의 변화 추이 확인

### 🚘 2. 자동차·운전면허 분석

#### 자동차 등록

-   전체 자동차 등록 현황
-   연도별 자동차 등록 현황
-   지역별 자동차 등록 현황
-   차종별 자동차 등록 현황
-   용도별 자동차 등록 현황

#### 운전면허

-   성별 운전면허 현황
-   연령대별 운전면허 현황
-   지역별 운전면허 현황

### 🚨 3. 교통사고 분석

#### 가해운전자

-   가해운전자 연령대별 사고
-   가해운전자 연령대·시간대별 사고

#### 고령운전자

-   고령운전자 사고유형·시간대 분석
-   고령운전자 월별·시간대 분석
-   고령운전자 지역별·월별 분석

#### 통합 교통사고

-   지역별 교통사고
-   연령대별 교통사고
-   기상상태별 교통사고

### 🏛️ 4. 정책·제도 분석

#### 운전면허 자진반납 이용 안내

-   신청 대상 확인
-   준비물 확인
-   신청 장소 안내
-   반납 신청 및 면허 취소 절차
-   지원혜택 확인

#### 고령운전자 교통안전교육

지역별 교육 공급량을 비교하여 **지역 간 교육 공급 격차**를 확인합니다.

-   지부 평균 교육 규모
-   최대·최소 지역 공급량 차이
-   최대/최소 공급 배율
-   상위 3개 지부 공급 집중도
-   평균 대비 지역별 공급 수준

> 교육 공급량은 `capacity` 합계를 기준으로 계산하며, 지역별 고령운전자
> 인구나 실제 교육 수요를 반영한 수요 대비 공급지표는 아닙니다.

#### 고령운전자 정책

-   전국 고령운전자 정책
-   지역 특화 고령운전자 안전정책
-   운전면허 자진반납 지원정책

#### 2023 vs 2025 운전면허 자진반납 비교

-   지역별 자진반납 비교
-   연령별 자진반납 비교
-   자진반납 건수 증감
-   증감률 분석

## 🚀 실행 방법

### 1. 프로젝트 다운로드

``` bash
git clone <repository-url>
cd SAFE
```

### 2. 가상환경 생성 및 활성화

``` bash
python -m venv .venv
```

Windows:

``` bash
.venv\Scripts\activate
```

### 3. 패키지 설치

``` bash
pip install streamlit pandas numpy plotly sqlalchemy pymysql
```

`requirements.txt`가 있는 경우:

``` bash
pip install -r requirements.txt
```

### 4. 데이터베이스 연결

`database/connection.py`에서 사용하는 MySQL 접속 환경을 설정합니다.

> DB 비밀번호, API Key 등 민감한 정보는 GitHub 저장소에 직접 업로드하지
> 않습니다.

### 5. Streamlit 실행

``` bash
streamlit run streamlit/app.py
```

## 💡 기대 효과

SAFE는 분리되어 있던 **인구·고령화·자동차·운전면허·교통사고·정책
데이터**를 하나의 서비스에서 지역 단위로 연결해 확인할 수 있도록 합니다.

특히 고령운전자와 관련하여 단순 사고 건수만 보여주는 것이 아니라
**지역별 사고 특성, 교통안전교육 공급 격차, 운전면허 자진반납 현황과
지원정책, 인구·자동차·면허 현황**을 함께 제공하여 지역별 교통안전 상황을
종합적으로 파악할 수 있도록 구성했습니다.

이를 통해 정부·지자체가 지역별 현황을 비교하고 향후 고령화와 교통환경
변화에 필요한 정책 검토의 기초자료로 활용할 수 있습니다.

## ⚠️ 분석 결과 해석 시 주의사항

-   데이터별 수집 시점과 집계 기준이 다를 수 있습니다.
-   연도별 비교 시 동일한 집계 기준인지 확인해야 합니다.
-   교육 `capacity`는 교육 공급 규모이며 실제 교육 이수자 수와 동일하지
    않을 수 있습니다.
-   지역별 단순 건수 비교는 지역 인구와 자동차·운전자 규모의 영향을 받을
    수 있습니다.
-   정책 정보는 시행 시점과 지방자치단체에 따라 변경될 수 있습니다.
-   정책 시행 전후의 변화만으로 정책 효과의 인과관계를 직접 단정할 수
    없습니다.
-   미래전망은 과거 데이터의 추세를 기반으로 한 참고 분석이며 실제
    미래값을 보장하지 않습니다.
